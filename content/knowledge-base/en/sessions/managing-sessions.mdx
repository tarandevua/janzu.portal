Session records help practitioners document their work and connect participant feedback with certification progress.

## Before creating a session

Confirm the session date, duration, location, and participant contact details. Use only information that participants have agreed to share.

## Create a session

1. Open **Sessions** from the portal sidebar.
2. Select the action to add a session.
3. Enter the required details and review them before saving.
4. Send or copy the feedback link when the workflow makes it available.

## Validation

A session becomes validated when the required feedback is received and linked to the session. Validated sessions can contribute to certification progress.

When feedback arrives, the practitioner receives one notification with the Session Participant, session date, rating, and a link to that exact feedback record. The link shows the record only to a signed-in user who is authorized to review it.

## Correcting a record

If you notice an error, update the session before relying on it for reporting or certification. Contact an administrator if a locked record needs correction.
