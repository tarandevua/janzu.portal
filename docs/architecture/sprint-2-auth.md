# Sprint 2 - Authentication Foundation

## Goal

Create the first runnable Next.js foundation with English and Spanish localization, ShadCN-compatible UI primitives, and Supabase magic link authentication.

## Included

- Next.js App Router structure.
- Locale-prefixed routes for English and Spanish.
- Supabase server client and auth callback.
- Magic link login page using ShadCN-style components.
- Protected dashboard placeholder.
- Zod validation for auth input.
- Unit tests for locale support and login validation.

## Deferred

- RBAC role checks.
- User profile onboarding.
- Dashboard navigation shell.
- Production rate limiting.
